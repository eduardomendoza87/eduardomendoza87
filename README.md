## Sobre mí

No solo estudio ingeniería de software — construyo productos mientras estudio.

Actualmente tengo 4 proyectos activos en desarrollo, cofundo una micro empresa de software,
y trabajo con metodologías reales como Scrum y Jira desde la universidad.
Mi enfoque está en el frontend con React y en diseñar primero en Figma antes de escribir
una sola línea de código.

- 🏗️ **Cofundador** de M&B Studio Dev · Micro empresa de software
- 🔭 **Proyecto principal activo:** Sistema de gestión de inventarios con tecnología NFC

- 🎓 Ingeniería en Sistemas Computacionales · México
- ⚡ **Fuera del código:** Atleta de gym
